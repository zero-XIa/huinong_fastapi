# 惠农平台功能列表

## 用户模块P0

### 用户注册
- **说明**：创建新账号
- **输入**：用户名、密码、手机号（可选）
- **输出**：用户信息（id, username, phone, elder_mode, create_time）
- **备注**：手机号选填；用户名唯一；密码后端使用bcrypt哈希存储
### 用户登录
- **说明**：验证身份
- **输入**：用户名、密码
- **输出**：token + 用户信息
- **备注**：token 后续请求需携带（Header: Authorization）；返回的 token 为 JWT，有效期 2 小时。
### 获取个人信息
- **说明**：查看当前登录用户信息
- **输入**：token
- **输出**：用户信息（id, username, phone, elder_mode, create_time）
- **备注**：手机号需打码显示（如 `138****0000`）
### 更新个人信息
- **说明**：修改手机号、长辈模式开关
- **输入**：token + 可修改字段（phone, elder_mode）
- **输出**：更新后的用户信息
- **备注**：手机号需唯一校验；elder_mode 为布尔值
### 修改密码
- **说明**：更改登录密码
- **输入**：token、原密码、新密码
- **输出**：成功/失败
- **备注**：新密码需符合复杂度规则（长度 8-20，含字母+数字）
### 退出登录
- **说明**：清除本地 token
- **输入**：无
- **输出**：无
- **备注**：前端清理存储，跳转登录页，后端无专用接口
## 资讯模块P0

### 资讯列表（分页）
- **说明**：分页获取资讯卡片，支持分类筛选
- **输入**：skip（默认0）、limit（默认10）、category（可选，如“政策”“农技”“市场”“预警”）
- **输出**：`{ total: int, list: [{ id, title, cover_url, publish_time, view_count }] }`
- **备注**：不需要认证；分类筛选为可选；按发布时间倒序排列
### 资讯详情
- **说明**：查看完整资讯内容，自动增加阅读量
- **输入**：资讯 id（路径参数）
- **输出**：完整资讯对象（含 id, title, content, category, cover_url, publish_time, view_count）
- **备注**：不需要认证；后端自动将 view_count 加 1
## 病害识别模块P0

### 上传图片快速识别（独立页面）
- **说明**：用户拍照或从相册选择作物图片，后端调用独立图像识别 API 获取病害名称及置信度，再将病害名称发送给 Dify 工作流 A（知识库检索 + 固定模板输出），返回标准防治建议。单次输出，不保留对话上下文。
- **输入**：图片文件（jpg/png，≤10MB）、token
- **输出**：`{ id, disease_name, confidence, advice, image_url, create_time }`
- **备注**：图片保存到服务器或云存储，返回 URL；识别 API 可用百度/阿里植物识别；Dify 工作流 A 仅根据病害名检索知识库，输出固定格式建议（temperature 低）；结果存入 `tb_identification` 表；页面无继续提问输入框
### 识别历史列表
- **说明**：分页查看当前用户的历史识别记录，支持点击某条记录查看详情或“继续问诊”
- **输入**：token、skip（默认0）、limit（默认10）
- **输出**：`{ total, list: [{ id, disease_name, confidence, advice, image_url, create_time }] }`
- **备注**：按创建时间倒序排列；每条记录提供“继续问诊”按钮，跳转到问诊页面并携带病害名称
### 删除识别记录
- **说明**：删除某条历史识别记录
- **输入**：token、记录 id
- **输出**：成功/失败
- **备注**：只能删除自己的记录；物理删除或软删除均可
## 问诊模块P0

### 纯文本问答
- **说明**：用户输入文本问题，直接调用 Dify 工作流 B（开放问答，支持多轮对话，保留上下文）
- **输入**：token、content（用户问题）、session_id（可选，首次对话不传，后端生成并返回）
- **输出**：Dify 回答文本（可先实现完整返回，后续升级流式）
- **备注**：Dify 工作流 B 使用知识库但允许自由发挥（temperature 较高）；消息存入 `tb_message` 表（role=user/ai）；session_id 用于关联同一会话
### 图片辅助问答（问诊页面内）
- **说明**：用户在问诊页面可上传图片并可选输入文字，后端先调用图像识别 API 得到病害名称及置信度，然后将病害名称和用户文字组合成增强 prompt 发送给 Dify 工作流 B，Dify 返回基于知识库的开放回答（支持多轮对话）
- **输入**：图片文件、可选文字（text）、token、session_id（可选）
- **输出**：Dify 回答文本
- **备注**：图片识别复用快速识别模块的能力，但**本次识别结果不存入识别历史表**（仅作为问答上下文）；最终发给 Dify 的 query 格式示例：“用户上传了一张图片，识别为【稻瘟病】，置信度 0.96。用户补充问题：叶子有褐色斑点。请给出防治建议。”；消息存入 `tb_message` 表；同一会话中可继续追问
### 获取历史会话列表
- **说明**：查看用户所有对话会话（每个会话以首次提问的前20字为标题）
- **输入**：token、skip、limit
- **输出**：`{ total, list: [{ session_id, title, last_message_time }] }`
- **备注**：按最后消息时间倒序；会话元信息可单独建表或从 `tb_message` 聚合查询
### 加载会话历史消息
- **说明**：查看某个会话内的所有消息（用于恢复对话）
- **输入**：token、session_id、skip、limit
- **输出**：`{ total, list: [{ role, content, create_time }] }`
- **备注**：消息按时间正序排列
### 删除会话
- **说明**：删除整个对话会话及其所有消息
- **输入**：token、session_id
- **输出**：成功/失败
- **备注**：物理删除 `tb_message` 中该 session_id 的所有记录
## 长辈模式P1

### 长辈模式开关
- **说明**：用户在“我的”页面可开启/关闭长辈模式，后端存储用户偏好（elder_mode 字段），前端根据该字段实时切换全局样式
- **输入**：token、elder_mode（布尔值）
- **输出**：更新后的用户信息（含 elder_mode）
- **备注**：调用更新个人信息接口（PUT /users/me）；样式切换无需重启应用，实时生效
### 全局字体放大
- **说明**：长辈模式开启后，全局字体尺寸放大：标题≥20px，正文≥18px，按钮文字≥19px
- **输入**：elder_mode 状态
- **输出**：界面字体变化
- **备注**：符合国家适老化标准；使用 MediaQuery 或全局 TextStyle 统一控制
### 高对比度配色
- **说明**：长辈模式下，文字使用深灰色（#333333），背景使用浅米色（#F5F5DC），避免浅色文字+浅色背景
- **输入**：elder_mode 状态
- **输出**：界面颜色变化
- **备注**：可复用 Flutter 主题切换机制，定义两套 ThemeData
### 按钮与交互区域放大
- **说明**：长辈模式下，按钮高度≥50px，内边距增加，圆角≥12px；点击区域相应扩大
- **输入**：elder_mode 状态
- **输出**：按钮尺寸和间距变化
- **备注**：使用条件样式或全局 ButtonStyle
### 防抖动与简化动画P2
- **说明**：长辈模式下，减少或禁用复杂动画（如页面过渡、滑动效果），避免误触
- **输入**：elder_mode 状态
- **输出**：动画时长缩短或禁用
- **备注**：可选择性实现，非核心功能；作为加分项

## 后台管理P1

### 管理员登录
- **说明**：管理员使用与普通用户相同的登录页面，输入用户名密码，后端返回 token 及角色信息（role=admin），前端根据角色跳转到独立的管理后台界面
- **输入**：用户名、密码
- **输出**：token + 用户信息（含 role=admin）
- **备注**：后端用户表需增加 role 字段（默认 user，管理员账号需手动插入或通过初始化脚本创建）；登录接口与普通用户共用
### 资讯管理（列表）
- **说明**：管理员在独立的管理后台查看所有资讯列表，支持分页、按标题搜索、按分类筛选，显示每条资讯的 id、标题、分类、发布时间、阅读量，并提供“编辑”“删除”按钮
- **输入**：token、skip、limit、keyword（可选，按标题模糊搜索）、category（可选）
- **输出**：`{ total, list: [{ id, title, category, cover_url, publish_time, view_count }] }`
- **备注**：需要管理员权限；可复用 `GET /api/v1/news` 接口，后端根据 `role=admin` 返回全量数据（不限制用户）；或单独新增 `GET /api/v1/news/admin/list`
### 新增资讯
- **说明**：管理员在管理后台点击“新增”，弹出表单填写标题、正文、分类、封面图 URL（可选），提交后创建资讯
- **输入**：token、title、content、category、cover_url（可选）
- **输出**：新建的资讯对象
- **备注**：需要管理员权限；调用 POST /api/v1/news；封面仅支持 URL，不处理文件上传
### 编辑资讯
- **说明**：管理员在资讯列表中点击“编辑”，弹出表单预填当前内容，修改后提交更新
- **输入**：token、资讯 id、可修改字段（title, content, category, cover_url）
- **输出**：更新后的资讯对象
- **备注**：需要管理员权限；调用 PUT /api/v1/news/{id}；支持部分字段更新
### 删除资讯
- **说明**：管理员点击“删除”，确认后删除该资讯（软删除或物理删除）
- **输入**：token、资讯 id
- **输出**：成功/失败
- **备注**：需要管理员权限；调用 DELETE /api/v1/news/{id}；建议软删除（增加 is_deleted 字段，列表中不显示已删除的资讯）
### 用户列表查看
- **说明**：管理员在管理后台查看所有注册用户，支持分页、按用户名或手机号搜索，显示用户 id、用户名、手机号（打码）、注册时间、长辈模式状态。不提供编辑或删除用户功能
- **输入**：token、skip、limit、keyword（可选，按用户名/手机号搜索）
- **输出**：`{ total, list: [{ id, username, phone, elder_mode, create_time }] }`
- **备注**：需要管理员权限；调用 GET /api/v1/users/admin/list（后端需新增该接口，仅限 admin 角色访问，返回所有用户信息）
### 退出登录
- **说明**：管理员在管理后台点击“退出登录”，清除本地 token，跳转到登录页
- **输入**：无
- **输出**：无
- **备注**：前端清理存储；后端无需专用接口；与普通用户退出逻辑相同
